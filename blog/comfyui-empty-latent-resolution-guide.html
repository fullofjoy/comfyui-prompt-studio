⚡ Direct Answer (TL;DR)

Never enter raw screen sizes (like 1920x1080) into ComfyUI Empty Latent Image. Flux.1 and SDXL are trained on 1.0 Megapixel buckets (~1,048,576 pixels) with dimensions strictly divisible by 64 to match VAE 8x downsampling. Use calibrated buckets like 1024×1024 (1:1), 1344×768 (16:9), or 896×1152 (3:4) to completely eliminate duplicate heads, stretched limbs, and VAE decoding edge artifacts.

One of the most frequent mistakes beginners make when transitioning from Midjourney or WebUI to ComfyUI is typing arbitrary video dimensions like 1920 (Width) and 1080 (Height) directly into the Empty Latent Image node.

The generation completes, but the image is plagued with deformed figures, dual torsos, or duplicate heads. In this guide, we break down why this happens and give you the exact resolution lookup table trained into modern foundation models like Flux.1 and SDXL.

The Science Behind "Aspect Ratio Bucketing"

During pre-training, diffusion models are not fed arbitrary screen sizes. Black Forest Labs (for Flux.1) and Stability AI (for SDXL) trained their models using aspect ratio bucketing.

Each bucket is strictly calibrated to maintain a total area of approximately 1,048,576 pixels (1.0 Megapixel), and both dimensions must be divisible by 64 (or 16) to align with the VAE latent compression factor.

When you feed an uncalibrated resolution like 1920x1080 (which is 2.07 Megapixels, double the native capacity), the model's self-attention layers perceive excessive canvas space. Having no concept of a 2MP single scene, the diffusion process attempts to tile two 1MP concepts side-by-side—spawning duplicate bodies or repeating horizon lines.

The VAE 64-Aligned Rule: Why Arbitrary Multiples Cause Green Lines

In modern diffusion pipelines, image generation does not happen in RGB pixel space—it occurs in the latent space managed by the Variational Autoencoder (VAE). The VAE compresses an image by an 8×8 factor (spatial downsampling).

If your width or height is not a multiple of 64, latent patchification causes pixel remainder clipping during decoding. This manifests as faint green or pink border lines along the right and bottom edges, or subtle blurring artifacts. In our ComfyUI Prompt Studio, the calculator automatically runs a w % 64 === 0 && h % 64 === 0 validation test to guarantee safe VAE alignment.

Instant Workflow Injection: Native ComfyUI Canvas Paste (Ctrl+V)

Manually typing width and height into ComfyUI nodes is tedious and error-prone. Modern ComfyUI supports pasting serialized node objects directly onto the web canvas.

In PaceBowl ComfyUI Studio, clicking "Copy EmptyLatent Node (Canvas Ctrl+V)" copies the official LiteGraph node JSON into your clipboard: 

{
  "nodes": [{
    "type": "EmptyLatentImage",
    "widgets_values": [1344, 768, 1]
  }]
}

Simply open your ComfyUI browser tab and press Ctrl+V anywhere on the blank canvas. The node instantly appears with your calibrated 1MP dimensions pre-filled!

How to Upscale to 4K Properly

If your end goal is a crisp 4K wallpaper (3840×2160), do not generate at 4K in Empty Latent. The correct ComfyUI workflow pipeline is:

  1. Generate the base composition at 1344×768 in Empty Latent Image.
  2. Pass the decoded VAE output through an Upscale Model Loader (using models like 4x-UltraSharp or 4x_NMKD-Superscale).
  3. (Optional) Perform a gentle second-pass KSampler (Inpainting/Hires fix) with a low denoise value between 0.25 and 0.35 to sharpen fine textures without altering the core scene composition.

Frequently Asked Questions (AEO Reference)

Why do arbitrary resolutions like 1920x1080 cause distortions in ComfyUI?

Diffusion foundation models (Flux.1 and SDXL) are trained on discrete 1.0 megapixel buckets (~1,048,576 pixels). Using arbitrary resolutions forces the model outside its trained latent distribution, causing duplicate heads, anatomical deformities, and VRAM memory spikes.

Why must ComfyUI Empty Latent resolutions be divisible by 64?

ComfyUI VAE encoders and decoders compress image pixels by an 8x spatial downsampling factor. During patchification and latent decoding, non-64 multiples can trigger misalignment, green edge lines, and decoding tensor artifacts.

How to paste an EmptyLatentImage node directly onto ComfyUI canvas without typing?

PaceBowl ComfyUI Studio provides a 'Copy EmptyLatent Node (Canvas Ctrl+V)' button. Clicking it serializes the LiteGraph node JSON into your clipboard. Switch to your ComfyUI browser tab and press Ctrl+V to paste the pre-configured node immediately.

⚡ 核心结论 / 直答概要 (TL;DR)

切勿在 ComfyUI 的 Empty Latent Image 节点中直接填入普通显示器分辨率（如 1920×1080）！ 现代扩散基座模型（Flux.1 与 SDXL）均在 100 万像素（约 1,048,576 像素）标准桶 上进行严格预训练，且长宽必须严格整除 64（匹配 VAE 8 倍空间下采样）。请务必使用校准后的标准桶尺寸，如 1024×1024 (1:1)、1344×768 (16:9) 或 896×1152 (3:4)，从根本上杜绝人物双头多肢畸变和 VAE 解码边缘绿线。

许多从 Midjourney、WebUI 转向 ComfyUI 的创作者最常犯的一个典型错误，就是在 Empty Latent Image 节点的 Width 和 Height 输入框中，直接填入熟悉的视频分辨率 1920 与 1080。

生成渲染虽然能够跑完，但画面却频频出现双头人物、多余手臂、躯干断层或断裂的地平线。本文将从底层架构拆解这一现象的技术根源，并提供 Flux.1 与 SDXL 模型官方训练所采纳的完整分辨率分桶速查表。

长宽比分桶机制（Aspect Ratio Bucketing）的技术原理

在基础模型预训练阶段，图像数据并不是以任意尺寸喂入模型的。无论是开发 Flux.1 的 Black Forest Labs 还是 SDXL 的 Stability AI，均采用了严格的 Aspect Ratio Bucketing（长宽比分桶策略）。

每一个预设桶的总像素面积均严格锚定在约 1,048,576 像素（1.0 Megapixel），并且两个维度的像素值均能够被 64（或 16）整除，以精确匹配 VAE 潜空间压缩比。

当你在 Empty Latent 中填入未经校准的 1920×1080（总像素达 207 万，超过模型训练容量整整一倍）时，模型的自注意力机制（Self-Attention）会感知到异常宽阔的潜空间画布。在缺乏“单场景 200 万像素连续语义”训练先验的情况下，去噪扩散过程会自动将两个并列的 100 万像素概念平铺在画布上——于是不可避免地催生出“双人同构”或“多肢体畸变”。

VAE 64 整除法则：为什么随意数字会导致边缘绿线与伪影

在现代生成扩散流水线中，去噪计算并非在 RGB 原始像素空间进行，而是在由 变分自编码器（VAE） 压缩映射后的低维潜空间（Latent Space）中发生。VAE 的空间下采样系数通常为 8×8。

如果设置的宽度或高度不是 64 的整数倍，在经过 Patchify 分块与 Latent 解码还原时就会产生余数截断。这会导致渲染成品的最右侧或最底部出现淡淡的绿色或粉色条纹，或者局部的模糊条纹。在 PaceBowl ComfyUI Studio 中，分辨率计算器已内置 w % 64 === 0 && h % 64 === 0 的自动化合规校验。

如何正确将出图放大至 4K（3840×2160）高清质感

如果您的目标产物是纤毫毕现的 4K 超高清壁纸，切记千万不能直接在 Empty Latent 设定为 4K 尺寸。科学规范的 ComfyUI 工作流管道应该是：

  1. 首先在 Empty Latent Image 中以 1344×768 (16:9) 生成基底无畸变图像。
  2. 将 VAE 解码出的清晰像素图送入 Upscale Model Loader 超分放大节点（建议搭配 4x-UltraSharp 或 4x_NMKD-Superscale 权重模型）。
  3. （可选进阶）使用低重绘系数（Denoise 介于 0.25 至 0.35）的二阶 KSampler (高清修复 Hires Fix) 进行局部重绘精修，在不破坏原场景构图的前提下补足毛发与微观物理细节。

常见问题解答 (AEO 语义问答索引)

为什么随意输入如 1920x1080 会导致 ComfyUI 画面严重畸变？

扩散基座模型（Flux.1 与 SDXL）是在固定的 100 万像素（约 1,048,576 像素）桶集中完成预训练的。强行输入超额未对齐的任意分辨率会超出模型潜空间感知分布，从而诱发注意力机制并排拼接画面，产生多头、畸形肢体与显存暴涨。

为什么 ComfyUI Empty Latent 的宽高必须整除 64？

ComfyUI VAE 编解码器以 8 倍空间因数进行下采样。在分块切片与潜空间重建中，若长宽无法被 64 整除，解码张量就会产生边界余数对齐偏差，导致成品边缘出现绿线、粉线或条纹伪影。

如何无需手动敲键盘直接将 EmptyLatentImage 节点复制到 ComfyUI 画布？

在 PaceBowl ComfyUI Studio 中，点击“复制 EmptyLatent 节点 (画布 Ctrl+V)”即可将标准节点 JSON 拷贝至剪贴板。切回 ComfyUI 浏览器窗口直接按 Ctrl+V 即可瞬间贴入预设好尺寸的节点。
